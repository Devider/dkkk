# Skills агента v2

Skill — папка `<name>/` с файлом `SKILL.md` (формат Agent Skills, спецификация §11). Новый сценарий подключается
только файлами в этом каталоге, без правки кода агента (FR-18). Каталог проверяется при сборке агента и на старте
сервиса при `AGENT_ENGINE=v2`: невалидный skill останавливает старт (AR-Q15).

```markdown
---
name: scenario-analysis            # = имя папки; строчные латинские буквы, цифры, одиночные «-»; ≤ 64
description: Что делает и на какие слова запроса реагирует (по-русски и по-английски); ≤ 1024 символов
metadata:
  include_tools: tool_a tool_b     # необязательно: инструменты каталога, которые skill открывает
---

# Тело: шаблон плана, правила выбора аргументов, типичные ошибки, формат раздела ответа (≤ 300 строк)
```

- `references/` — справочники, на которые тело ссылается (`/skills/<name>/references/...`).
- `evals.yaml` — примеры запросов с ожидаемым планом; модель их не читает.
- В корне каталога, кроме папок skills, допустим только этот `README.md`.
