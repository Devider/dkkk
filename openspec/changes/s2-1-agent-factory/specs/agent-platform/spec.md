# Spec Delta

## ADDED Requirements

### Requirement: AR-Q1 Модель агента по конфигурации

Агент v2 SHALL собираться с одной из трёх моделей, выбранных конфигурацией без изменения кода: GigaChat с подключением по api_key, GigaChat с подключением по сертификатам (переключатель `LOCAL` и параметры GigaChat, как в v1) и скриптовая модель с детерминированными ответами для тестов и демонстраций.

#### Scenario: GigaChat по api_key
- **WHEN** `AGENT_MODEL=gigachat`, `LOCAL=true` и задан `GIGACHAT_CREDENTIALS`
- **THEN** агент собирается с моделью GigaChat, аутентифицированной по ключу

#### Scenario: GigaChat по сертификатам
- **WHEN** `AGENT_MODEL=gigachat`, `LOCAL=true` и заданы клиентский сертификат и ключ
- **THEN** агент собирается с моделью GigaChat, подключённой по сертификатам

#### Scenario: Скриптовая модель
- **WHEN** `AGENT_MODEL=scripted` и `AGENT_SCRIPT_PATH` указывает на файл сценария
- **THEN** агент собирается со скриптовой моделью, проходит ход без сети и возвращает ответы из сценария по порядку

#### Scenario: Сценарий исчерпан
- **WHEN** скриптовой модели нужен ответ, а шаги сценария закончились
- **THEN** ход завершается понятной ошибкой «сценарий исчерпан», а не зависанием

### Requirement: AR-Q5 Параметры агента в конфигурации

Параметры агента v2 (выбор движка и модели, лимиты, пороги, режимы, пул движка) SHALL задаваться переменными окружения `AGENT_*` через настройки `config/agent` с безопасными значениями по умолчанию и SHALL быть перечислены в README с назначением и значением по умолчанию.

#### Scenario: Значения по умолчанию
- **WHEN** ни одна переменная `AGENT_*` не задана
- **THEN** сервис работает на v1, а параметры v2 имеют значения по умолчанию из настроек

#### Scenario: Переопределение переменной окружения
- **WHEN** задана переменная `AGENT_*`
- **THEN** соответствующий параметр агента принимает её значение без изменения кода

#### Scenario: Документация параметров
- **WHEN** в настройках `config/agent` есть параметр
- **THEN** он описан в таблице параметров README с переменной окружения и значением по умолчанию

### Requirement: AR-Q15 Сопровождаемость кода агента

Новый код агента v2 SHALL проходить `ruff check` и `ruff format` без замечаний, иметь оценку pylint выше 7 и покрытие тестами не ниже 80 %. Промпты встроенных middleware, которые видит модель, SHALL быть на русском.

#### Scenario: Русские промпты встроенных middleware
- **WHEN** агент собран
- **THEN** системные вставки и описания инструментов встроенных middleware, которые видит модель, — на русском

#### Scenario: Проверки качества
- **WHEN** запускаются проверки качества для `api/v2`
- **THEN** `ruff` без замечаний, pylint > 7, покрытие ≥ 80 %
