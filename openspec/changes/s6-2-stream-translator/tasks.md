Все тесты — `AgentFactory` со всем стеком на `ScriptedChatModel`, с фейками движка и реестра из `tests/unit/v2` (`inline_gate`, `uploaded_store`, как в `test_runtime.py::TestFactoryTurn`), класс `TestStreamScenarios` в `test_stream_turn.py`. Каждый сценарий прогоняется через `stream()` и через `answer()` на новом агенте с тем же скриптом. Все события каждого сценария проверяются `hygiene.violations` → пусто.

- [x] 5.1 U2 (FR-22): план → `resolve_terms` → `run_scenarios` → `derive` → закрытие плана → ответ. Проверка: типы событий по порядку `turn.started`, `plan`, пары `tool.*` с `plan` между ними, `phase(checking)`, `answer(full)`; `seq` без пропусков; текст `answer` = возврат `answer()`; подписи без ID
- [x] 5.2 Ранний ответ и выдуманное число (FR-24, FR-26): (а) текст при открытом шаге → `PlanCompletionGuard` возвращает к работе; (б) ответ с числом вне результатов → перегенерация `AnswerGroundingGuard`; (в) повторно выдуманное число → «н/д» с оговоркой. Проверка: тексты отклонённых ответов и напоминаний не встречаются ни в одном событии; `answer` = возврат `answer()`, в (в) — с «н/д»
- [x] 5.3 Исходы `answer`: нет загруженной модели и запрос на немецком (U9) → `turn.started`, `answer(refusal)` без `tool.*`; `AGENT_MAX_MODEL_CALLS=2` → `partial`; истёкший дедлайн (подставные часы `cancellation._now`) → `partial`; `missing_input` → шаг `blocked` (U5) → `clarify`. Проверка: исход и равенство текста с `answer()` в каждом случае
- [x] 5.4 Ошибки инструментов (FR-22): `resolve_terms` с `ambiguous_term`, расчёт с `unknown_id`, `engine_unavailable` после системного повтора (U7), попадание `CalcCache`. Проверка: исходы `retry`, `retry`, `failed`, `ok`; тексты из таблицы D7; кодов и `hint` в событиях нет; у попадания в кэш — та же пара событий
- [x] 5.5 Терминальные ошибки: модель бросает `StopEventError` на втором вызове; инструмент бросает необработанное исключение вне конверта (подменённый `tool_errors`). Проверка: последнее событие — `error` (`unavailable` / `failed`), `answer` нет, событий после терминального нет, блокировка свободна. - [x] 5.6 Уход потребителя (AR-Q17): движок с задержкой 0,5 с, потребитель выходит из `async for` после `tool.started` расчёта. Проверка: `context.cancel` выставлен; фейковый движок довёл расчёт (`finished == 1`); вызовов модели после расчёта нет; сразу после выхода сессия занята (`acquire` → `TurnBusyError`), после завершения задачи свободна; следующий `answer()` в той же сессии проходит
- [x] 5.7 Медленный потребитель: читает с `await asyncio.sleep(0.2)` на событие. Проверка: задача хода завершилась раньше, чем потребитель прочитал половину событий; все события получены по порядку
