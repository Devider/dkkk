Story S0.6 · требований FR / AR-Q / ADR нет · §15 E0

## Why

Агент v2 построен на `langchain`, `langgraph` и `deepagents` с жёстко закреплёнными версиями (S0.1), а API этих библиотек быстро меняется. Например, закрепление skills (`pinned_skills`) появилось в `deepagents` только с 0.7.23. Ассистент разработки должен сверяться с актуальной документацией, а не с памятью модели. Сервер `langchain-docs` уже подключён в `.mcp.json` (коммит `39530d7`), но в CLAUDE.md и AGENTS.md это не описано. По критерию S0.6 описание обязательно.

## What Changes

- Раздел «LangChain documentation (MCP)» в CLAUDE.md и AGENTS.md: какой сервер подключён, где он настроен, его инструменты, когда к нему обращаться и как сверять ответ с закреплёнными версиями.
- Проверка критерия приёмки: ассистент получает ответ через MCP на вопрос по API, который использует v2. Результат — в tasks.md.

**Вне рамок:** другие MCP-серверы (`docs-langchain`, `reference-langchain` из пользовательских настроек — они не входят в репозиторий); доступ к MCP из внутреннего контура (публичный `docs.langchain.com`); изменения кода и спек (`skip_specs`).
