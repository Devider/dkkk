# Spec Delta

## ADDED Requirements

### Requirement: FR-7 Ошибка инструмента с кодом и подсказкой

Любая ошибка инструмента SHALL возвращаться модели как результат вызова в виде `{status: "error", error, code, hint}`, а не как необработанное исключение. `code` SHALL быть одним из кодов справочника, `hint` SHALL называть следующий шаг. Текст исключения, traceback и внутренние пути MUST NOT попадать в `error` и `hint`.

#### Scenario: Неизвестный ID индекса
- **WHEN** модель вызывает расчётный инструмент с ID, которого нет в индексе модели
- **THEN** результат вызова — конверт ошибки с кодом `unknown_id` и подсказкой вызвать `resolve_terms`, движок не запускается

#### Scenario: Непредвиденное исключение
- **WHEN** доменная функция падает с исключением, не известным справочнику
- **THEN** модель получает конверт с кодом `internal_error` и общей подсказкой, без текста исключения

#### Scenario: У каждой ошибки есть код и подсказка
- **WHEN** перебираются все ошибки, которые могут вернуть зарегистрированные инструменты
- **THEN** у каждой есть `code` из справочника и непустой `hint`

### Requirement: FR-7 Справочник кодов ошибок

Справочник SHALL содержать коды `invalid_args`, `unknown_id`, `ambiguous_term`, `term_not_found`, `no_values`, `bad_units`, `missing_input`, `engine_unavailable`, `engine_timeout`, `plan_required`, `limit_exceeded`, `cancelled`, `internal_error`; у каждого — подсказка по умолчанию, говорящая модели, что делать дальше. Инструмент MAY уточнить подсказку для конкретного случая.

#### Scenario: Подсказка по умолчанию
- **WHEN** ошибка создаётся только с кодом
- **THEN** её `hint` — подсказка этого кода из справочника

#### Scenario: Неизвестный код отклоняется
- **WHEN** код ошибки не входит в справочник
- **THEN** конверт не создаётся (ошибка разработки)

### Requirement: FR-7 Классификация результатов расчёта v1

Статусы и тексты расчётных функций v1 (`OK`, `WARNING`, `ERROR`) SHALL переводиться в конверт без правки расчётного кода: известные ошибки — в соответствующий код, нераспознанная ошибка — в `internal_error`. Результат подбора без найденных сценариев SHALL быть успехом с оговоркой, а не ошибкой.

#### Scenario: Не хватает входных данных
- **WHEN** расчёт возвращает ошибку «не указаны входные параметры» или «не удалось определить год»
- **THEN** модель получает код `missing_input`

#### Scenario: Строка без значений
- **WHEN** расчёт не находит ячейку выхода или входа для показателя из индекса
- **THEN** модель получает код `no_values` с подсказкой взять следующего кандидата

#### Scenario: Слишком большая сетка
- **WHEN** расчёт отклоняет сетку как слишком широкую
- **THEN** модель получает код `invalid_args` с подсказкой сузить диапазон или увеличить шаг

#### Scenario: Сбой движка
- **WHEN** расчёт падает из-за LibreOffice (UNO-мост, запуск `soffice`)
- **THEN** модель получает код `engine_unavailable`

#### Scenario: Цель не достигнута
- **WHEN** подбор входов не нашёл сценариев, дающих цель
- **THEN** результат — успех с оговоркой «цель не достигнута», а не ошибка

### Requirement: ADR-5 Единый конверт результата

Успешный результат каждого инструмента SHALL иметь вид `{status: "ok", result, data, numbers, notes, hint, ref}`: `result` — сводка на русском, `data` — компактные структурированные данные, `numbers` — список `{value, label, unit}` с числами результата, `notes` — оговорки. Серверные пути к файлам MUST NOT попадать в `data`.

#### Scenario: Сценарная сетка в конверте
- **WHEN** `run_scenarios` завершается успешно
- **THEN** конверт содержит сводку, таблицу сценариев в `data` и значения выходов по сценариям в `numbers` с подписями

#### Scenario: Подбор под цель в конверте
- **WHEN** `find_input_for_target` находит сценарии
- **THEN** `numbers` содержит найденные значения входов и значение выхода, `data` — найденные сценарии

#### Scenario: Серверные пути скрыты
- **WHEN** доменный результат содержит пути к сохранённым файлам
- **THEN** в конверте этих путей нет
