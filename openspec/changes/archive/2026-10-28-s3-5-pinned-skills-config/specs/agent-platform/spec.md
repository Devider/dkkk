## MODIFIED Requirements

### Requirement: AR-Q5 Параметры агента в конфигурации

Параметры агента v2 (выбор движка и модели, лимиты, пороги, режимы, пул движка) SHALL задаваться переменными окружения `AGENT_*` через настройки `config/agent` с безопасными значениями по умолчанию и SHALL быть перечислены в README с назначением и значением по умолчанию. Лимиты хода SHALL задаваться переменными `AGENT_MAX_MODEL_CALLS` (40), `AGENT_MAX_TOOL_CALLS` (30) и `AGENT_MAX_CALCS` (10), повторы вызова модели — `AGENT_LLM_RETRY_ATTEMPTS` (3) и `AGENT_LLM_RETRY_WAIT` (2 с), время хода — `AGENT_TURN_TIMEOUT` (300 с), порог выноса результата инструмента — `AGENT_RESULT_MAX_CHARS` (1500 символов); лимит меньше 1, неположительное время хода и порог выноса меньше 500 MUST отклоняться при старте. Бюджет запроса к модели SHALL задаваться `AGENT_MAX_PROMPT_TOKENS` (30 000 токенов), порог сжатия истории — `AGENT_SUMMARY_TRIGGER` (0.7 бюджета), сохраняемый хвост — `AGENT_SUMMARY_KEEP` (0.3 бюджета); бюджет меньше 20 000, доли вне интервала (0, 1) и хвост не меньше порога сжатия MUST отклоняться при старте. Закреплённые skills SHALL задаваться `AGENT_PINNED_SKILLS` (имена через запятую, по умолчанию `economic-answer`; пустая строка — ничего не закреплять).

#### Scenario: Значения по умолчанию
- **WHEN** ни одна переменная `AGENT_*` не задана
- **THEN** сервис работает на v1, а параметры v2 имеют значения по умолчанию из настроек

#### Scenario: Переопределение переменной окружения
- **WHEN** задана переменная `AGENT_*`
- **THEN** соответствующий параметр агента принимает её значение без изменения кода

#### Scenario: Документация параметров
- **WHEN** в настройках `config/agent` есть параметр
- **THEN** он описан в таблице параметров README с переменной окружения и значением по умолчанию

#### Scenario: Недопустимый лимит
- **WHEN** `AGENT_MAX_MODEL_CALLS`, `AGENT_MAX_TOOL_CALLS` или `AGENT_MAX_CALCS` меньше 1
- **THEN** настройки не загружаются, сервис не стартует с ошибкой проверки

#### Scenario: Недопустимое время хода
- **WHEN** `AGENT_TURN_TIMEOUT` не больше 0
- **THEN** настройки не загружаются, сервис не стартует с ошибкой проверки

#### Scenario: Недопустимый порог выноса
- **WHEN** `AGENT_RESULT_MAX_CHARS` меньше 500
- **THEN** настройки не загружаются, сервис не стартует с ошибкой проверки

#### Scenario: Недопустимый бюджет контекста
- **WHEN** `AGENT_MAX_PROMPT_TOKENS` меньше 20 000
- **THEN** настройки не загружаются, сервис не стартует с ошибкой проверки

#### Scenario: Недопустимые доли сжатия
- **WHEN** `AGENT_SUMMARY_TRIGGER` или `AGENT_SUMMARY_KEEP` вне интервала (0, 1), или `AGENT_SUMMARY_KEEP` не меньше `AGENT_SUMMARY_TRIGGER`
- **THEN** настройки не загружаются, сервис не стартует с ошибкой проверки

#### Scenario: Список закреплённых skills
- **WHEN** `AGENT_PINNED_SKILLS=" economic-answer , target-seeking,economic-answer"`
- **THEN** настройки дают список `economic-answer`, `target-seeking`: пробелы убраны, повтор отброшен, порядок сохранён; без переменной список — `economic-answer`
