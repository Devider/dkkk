# Spec Delta

## ADDED Requirements

### Requirement: AR-Q8 Конкурентность движка

Расчёты одной сессии SHALL выполняться по одному, даже если модель или параллельные ходы запросили несколько расчётов одновременно. Число одновременных расчётов в сервисе SHALL ограничиваться пулом процессов размера `AGENT_CALC_WORKERS`; лишние расчёты ждут свободного места.

#### Scenario: Два расчёта одной сессии
- **WHEN** в одной сессии одновременно запускаются два расчёта
- **THEN** второй начинается только после завершения первого

#### Scenario: Расчёты разных сессий
- **WHEN** две сессии одновременно запускают по расчёту и в пуле есть два места
- **THEN** расчёты идут параллельно

#### Scenario: Пул заполнен
- **WHEN** расчётов запрошено больше, чем мест в пуле
- **THEN** одновременно выполняется не больше `AGENT_CALC_WORKERS`, остальные ждут и выполняются после

### Requirement: AR-Q9 Event loop не блокируется

Пересчёт книги в LibreOffice SHALL выполняться в отдельном процессе, а не в потоке или на event loop сервиса, чтобы сервис отвечал на другие запросы во время расчёта.

#### Scenario: Сервис отвечает во время расчёта
- **WHEN** идёт пересчёт книги
- **THEN** задержка event loop сервиса не превышает 1 секунды

### Requirement: ADR-6 Таймаут расчёта без сирот

Расчёт дольше `AGENT_CALC_TIMEOUT` SHALL прерываться: модель получает `engine_timeout`, процессы этого расчёта, включая `soffice`, завершаются, пул пересоздаётся и принимает следующие расчёты. Сбой пула SHALL возвращаться как `engine_unavailable`.

#### Scenario: Зависший расчёт
- **WHEN** расчёт не завершается за `AGENT_CALC_TIMEOUT`
- **THEN** модель получает `engine_timeout` с подсказкой сузить сетку, и после этого в системе не остаётся процессов `soffice` этого расчёта

#### Scenario: Работа после таймаута
- **WHEN** после таймаута запускается новый расчёт
- **THEN** он выполняется в пересозданном пуле и завершается успешно

#### Scenario: Воркер пула упал
- **WHEN** процесс воркера аварийно завершается во время расчёта
- **THEN** модель получает `engine_unavailable`, а пул пересоздаётся для следующих расчётов
