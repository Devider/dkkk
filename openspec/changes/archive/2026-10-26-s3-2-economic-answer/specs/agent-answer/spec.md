# Spec Delta

## Purpose

Финальный ответ агента v2: структура и стиль ответа аналитика, язык, отсутствие служебных данных и подтверждение чисел источниками.

## ADDED Requirements

### Requirement: FR-12 Структура ответа

Аналитический ответ (ход с расчётом или выводом по модели) SHALL состоять из разделов в порядке: «Вывод» (1–3 предложения), «Ключевые цифры» (таблица), «Анализ» (чувствительность, запас прочности, драйверы), «Где в модели» (показатели и листы), «Оговорки» (допущения и невыполненное); пустые разделы SHALL опускаться, раздел «Вывод» MUST присутствовать. Структуру и стиль SHALL задавать skill `economic-answer`, закреплённый в каждом ходе: его текст SHALL попадать в контекст сессии один раз и повторно — только если его там больше нет. Ответ без расчёта (вопрос пользователю о недостающем, отказ, приветствие) SHALL даваться без разделов.

#### Scenario: Skill закреплён
- **WHEN** в новой сессии идёт первый ход до вызова модели
- **THEN** в контексте модели есть сообщение с текстом `economic-answer`, а в следующем ходе той же сессии второй копии не добавляется

#### Scenario: Закреплённый skill отсутствует
- **WHEN** закреплённого имени нет среди skills каталога
- **THEN** сборка агента завершается ошибкой с этим именем

#### Scenario: Проверка структуры
- **WHEN** проверка структуры получает аналитический ответ
- **THEN** ответ без раздела «Вывод», с разделами не по порядку, с выводом длиннее 3 предложений или с разделом «Ключевые цифры» без таблицы помечается как нарушение, а ответ с разделами по порядку и без пустых — как соответствующий

#### Scenario: Ответы eval на GigaChat
- **WHEN** eval прогоняет аналитические запросы по модели Methanex на GigaChat
- **THEN** ответы соответствуют структуре FR-12, а оценка аналитика — не ниже 4 из 5

### Requirement: FR-14 Язык и гигиена ответа

Ответ SHALL быть на деловом русском независимо от языка вопроса, включая служебные вставки самого агента (раздел невыполненного, отказы). В ответ MUST NOT попадать коды ошибок инструментов, тексты исключений и traceback, ID индекса модели (`IN…`, `OUT…`) и служебные имена инструментов.

#### Scenario: Вопрос на английском
- **WHEN** пользователь спрашивает на английском и ответ дополняется разделом невыполненного
- **THEN** весь ответ, включая этот раздел, — на русском

#### Scenario: Служебные данные в ответе
- **WHEN** проверка гигиены получает ответ с кодом ошибки (например, `missing_input`), `Traceback`, ID `IN12` или именем инструмента `run_scenarios`
- **THEN** каждое такое вхождение помечается как нарушение, а ответ без них на русском — как соответствующий

#### Scenario: Проверка ответов eval
- **WHEN** eval прогоняет ответы набора
- **THEN** ни один ответ не содержит кодов ошибок, traceback, ID индекса и имён инструментов
