# Spec Delta

## MODIFIED Requirements

### Requirement: ADR-5 Расчёт по ID индекса модели

Расчётные инструменты SHALL принимать входы и выходы модели в виде ID индекса модели. Адаптер SHALL переводить ID в канонические имена по индексу из контекста хода и вызывать доменную функцию с теми же аргументами, что и v1 для тех же показателей. До запуска движка аргументы SHALL проверяться по индексу модели; при нарушении модель получает ошибку с кодом, а движок не запускается. Недостающие год, цель и диапазоны MUST NOT подставляться по умолчанию.

#### Scenario: ID переводятся в канонические имена
- **WHEN** модель вызывает расчётный инструмент с ID входа и ID выхода
- **THEN** доменная функция получает канонические имена этих показателей из индекса модели текущего файла

#### Scenario: Логика расчёта не меняется
- **WHEN** один и тот же расчёт выполняется через инструмент v2 и напрямую через доменную функцию с каноническими именами
- **THEN** результаты совпадают

#### Scenario: ID вне индекса
- **WHEN** расчётный инструмент вызван с ID, которого нет в индексе модели
- **THEN** модель получает `unknown_id`, движок не запускается

#### Scenario: Недостающие данные не подставляются
- **WHEN** в вызове нет года, цели или диапазона для входа
- **THEN** модель получает `missing_input` с названием недостающего, движок не запускается и никакое значение по умолчанию не используется

#### Scenario: Выход без значений
- **WHEN** выход из индекса не имеет значений ни за один год (заголовок раздела)
- **THEN** модель получает `no_values` с подсказкой взять другого кандидата, движок не запускается

#### Scenario: Год вне горизонта выхода
- **WHEN** запрошен год, за который у выхода нет значения
- **THEN** модель получает `invalid_args` с перечнем доступных лет, движок не запускается

#### Scenario: Некорректный диапазон
- **WHEN** у входа начало диапазона больше конца или шаг не больше нуля
- **THEN** модель получает `invalid_args`, движок не запускается

#### Scenario: Сетка больше лимита
- **WHEN** произведение числа точек по всем входам больше `AGENT_MAX_GRID`
- **THEN** модель получает `invalid_args` с посчитанным размером и подсказкой сузить сетку, движок не запускается

#### Scenario: Единицы диапазона не совпадают с базовым значением
- **WHEN** базовое значение входа выражено в долях, а диапазон похож на проценты (или наоборот)
- **THEN** модель получает `bad_units` с базовым значением входа, движок не запускается

## ADDED Requirements

### Requirement: FR-11 Недостижимая цель — результат анализа

Если подбор входов не нашёл сценариев, дающих цель, инструмент SHALL возвращать успех с признаком `reachable: false`, ближайшей найденной точкой (значения входов и выхода) и оговоркой. Найденная цель SHALL помечаться `reachable: true`.

#### Scenario: Цель достигнута
- **WHEN** подбор находит сценарии, дающие цель в пределах допуска
- **THEN** результат — успех с `reachable: true` и найденными значениями входов

#### Scenario: Цель недостижима
- **WHEN** ни один проверенный сценарий не даёт цель в пределах допуска
- **THEN** результат — успех с `reachable: false`, ближайшей точкой в данных и числах результата и оговоркой «цель не достигнута»
