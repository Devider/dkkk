# Spec Delta

## MODIFIED Requirements

### Requirement: AR-Q15 Сопровождаемость кода агента

Новый код агента v2 SHALL проходить `ruff check` и `ruff format` без замечаний, иметь оценку pylint выше 7 и покрытие тестами не ниже 80 %. Промпты встроенных middleware, которые видит модель, SHALL быть на русском. Skills SHALL проверяться при сборке агента и при старте сервиса с `AGENT_ENGINE=v2`: невалидный skill MUST останавливать старт с ошибкой, называющей skill и нарушение, а не пропускаться молча.

#### Scenario: Русские промпты встроенных middleware
- **WHEN** агент собран
- **THEN** системные вставки и описания инструментов встроенных middleware, которые видит модель, — на русском

#### Scenario: Проверки качества
- **WHEN** запускаются проверки качества для `api/v2`
- **THEN** `ruff` без замечаний, pylint > 7, покрытие ≥ 80 %

#### Scenario: Невалидный skill останавливает старт
- **WHEN** в каталоге skills есть skill без `description`, с битым фронтматтером, с `name`, не совпадающим с папкой, или с неизвестным инструментом в `metadata.include_tools`
- **THEN** сборка агента и старт сервиса при `AGENT_ENGINE=v2` завершаются ошибкой со списком всех нарушений по каждому skill
