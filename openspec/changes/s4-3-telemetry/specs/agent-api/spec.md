## ADDED Requirements

### Requirement: AR-Q13 Журнал вызовов LLM и инструментов

При `AGENT_ENGINE=v2` на каждый вызов модели агента в журнал сервера SHALL писаться одна строка `LLM CALL` с `trace_id` (= `x-trace-id`), `turn_id`, номером вызова в ходе, временем вызова, токенами (prompt, completion, total — если модель их вернула), именами инструментов, которые модель вызвала, и кодом ошибки, если вызов завершился исключением. На каждый вызов инструмента SHALL писаться одна строка `TOOL CALL` с `trace_id`, `turn_id`, именем инструмента, временем, статусом (`ok` / `error`) и кодом ошибки из конверта результата. Текст исключения MUST NOT попадать в строки `LLM CALL` и `TOOL CALL` — только код (класс исключения или код конверта). Исключение после записи строки SHALL распространяться дальше без изменений: телеметрия не меняет ход и ответ.

#### Scenario: Строка на каждый вызов модели
- **WHEN** ход делает два вызова модели, первый из которых вызывает `resolve_terms`
- **THEN** в журнале две строки `LLM CALL` с номерами 1 и 2, одним `turn_id`, `trace_id` запроса, временем и токенами; в первой среди инструментов есть `resolve_terms`

#### Scenario: Строка на каждый вызов инструмента
- **WHEN** модель вызывает инструмент, и он возвращает конверт ошибки с кодом `unknown_id`
- **THEN** в журнале строка `TOOL CALL` с именем инструмента, статусом `error` и кодом `unknown_id`

#### Scenario: Ошибка вызова модели
- **WHEN** вызов модели завершается исключением (например, StopEvent)
- **THEN** в журнале строка `LLM CALL` с кодом ошибки без текста исключения, а исключение доходит до API как раньше (StopEvent → 503)

#### Scenario: Ход без LLM
- **WHEN** ход завершается без вызова модели (нет файла, неподдерживаемый язык)
- **THEN** строк `LLM CALL` и `TOOL CALL` нет

### Requirement: AR-Q13 Дерево хода в Langfuse

Когда Langfuse включён, ход SHALL уходить в self-hosted Langfuse одной трассой с `langfuse_session_id = thread_id`, `langfuse_user_id = user_id` и тегом `agent_engine=<v1|v2>` по выбранному движку. Для v2 трасса SHALL содержать дерево хода: узлы middleware графа агента, вызовы модели с токенами, вызовы инструментов и вложенные вызовы смыслового слоя внутри вызова инструмента. Ключи, сертификаты и путь к файлу пользователя MUST NOT попадать в метаданные трассы. Когда Langfuse выключен или недоступен, ход SHALL выполняться без трассы, с тем же ответом.

#### Scenario: Метаданные трассы
- **WHEN** при `AGENT_ENGINE=v2` и включённом Langfuse пользователь задаёт вопрос
- **THEN** у трассы хода `session_id` = `"{user_id}:{session_id}"`, `user_id` = `x-user-id` и тег `agent_engine=v2`; при `AGENT_ENGINE=v1` — те же поля и тег `agent_engine=v1`

#### Scenario: Вложенный вызов смыслового слоя
- **WHEN** модель вызывает `resolve_terms`, а он обращается к LLM смыслового слоя
- **THEN** вызов LLM смыслового слоя виден в той же трассе дочерним узлом вызова `resolve_terms`

#### Scenario: Дерево хода
- **WHEN** ход делает план, сопоставление и расчёт
- **THEN** в трассе есть узлы middleware, вызовы модели, `write_todos`, `resolve_terms`, расчётный инструмент и итоговый узел выжимки хода

#### Scenario: Langfuse выключен
- **WHEN** Langfuse выключен или handler недоступен
- **THEN** ход завершается тем же ответом, а в журнале есть строки `LLM CALL` и `TOOL CALL`
