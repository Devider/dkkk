# agent-answer Specification

## Purpose

Финальный ответ агента v2: структура и стиль ответа аналитика, язык, отсутствие служебных данных и подтверждение чисел источниками.

## Requirements

### Requirement: FR-12 Структура ответа

Аналитический ответ (ход с расчётом или выводом по модели) SHALL состоять из разделов в порядке: «Вывод» (1–3 предложения), «Ключевые цифры» (таблица), «Анализ» (чувствительность, запас прочности, драйверы), «Где в модели» (показатели и листы), «Оговорки» (допущения и невыполненное); пустые разделы SHALL опускаться, раздел «Вывод» MUST присутствовать. Структуру и стиль SHALL задавать skill `economic-answer`, закреплённый в каждом ходе: его текст SHALL попадать в контекст сессии один раз и повторно — только если его там больше нет. Ответ без расчёта (вопрос пользователю о недостающем, отказ, приветствие) SHALL даваться без разделов.

#### Scenario: Skill закреплён
- **WHEN** в новой сессии идёт первый ход до вызова модели
- **THEN** в контексте модели есть сообщение с текстом `economic-answer`, а в следующем ходе той же сессии второй копии не добавляется

#### Scenario: Закреплённый skill отсутствует
- **WHEN** закреплённого имени нет среди skills каталога
- **THEN** сборка агента завершается ошибкой с этим именем

#### Scenario: Проверка структуры
- **WHEN** проверка структуры получает аналитический ответ
- **THEN** ответ без раздела «Вывод», с разделами не по порядку, с выводом длиннее 3 предложений или с разделом «Ключевые цифры» без таблицы помечается как нарушение, а ответ с разделами по порядку и без пустых — как соответствующий

#### Scenario: Ответы eval на GigaChat
- **WHEN** eval прогоняет аналитические запросы по модели Methanex на GigaChat
- **THEN** ответы соответствуют структуре FR-12, а оценка аналитика — не ниже 4 из 5

### Requirement: FR-13 Числа ответа только из источников

Каждое проверяемое число финального ответа агента v2 SHALL быть найдено в источниках хода. Источники — числа результатов инструментов этого хода, числа выжимок прошлых ходов сессии и числа из сообщений пользователя. Производные числа (разница, процент изменения, запас до порога, точка пересечения, эластичность) SHALL считаться инструментом, а не моделью. Финальный ответ — это ответ модели без вызова инструментов, принятый проверкой завершения плана. Проверка SHALL применяться при любом режиме плана, включая `AGENT_PLAN_MODE=off`.

Правила сравнения:
- Число ответа подтверждено, если источник отличается от него по модулю не больше чем на половину единицы последнего записанного в ответе разряда и не больше чем на 0,5 % значения источника.
- Знак не учитывается: знак часто передан словом («снизится на 12»).
- Число со знаком `%` подтверждается и источником-долей, равным этому числу, делённому на 100 (`5 %` ↔ `0.05`).
- Не проверяются: годы (целые 1900–2100, записанные без разделителей, дробной части и `%`), номера пунктов списка в начале строки, числа, примыкающие к буквам обозначения (`P143`, `Q4`, `CO2`; множитель `3.5x` проверяется), даты (`31.12.2025`) и целые 0–10, записанные без дробной части и без `%`.
- Числа в другом масштабе или единицах (млн ↔ млрд) не пересчитываются и считаются неподтверждёнными.

Если в ответе есть неподтверждённые числа, модель SHALL получить отдельное сообщение пользователя. В нём перечислены эти числа и сказано получить их инструментом (производные — через `derive`) или убрать. Затем ход возвращается модели, и последним сообщением промпта не остаётся ответ модели. Число таких возвратов за ход SHALL ограничиваться настройкой `AGENT_GROUNDING_MAX_RETURNS` (по умолчанию 1, отрицательное значение MUST отклоняться при старте). Если возвраты исчерпаны, исчерпан лимит хода (FR-9) или истекло время хода (AR-Q10), ответ SHALL приниматься без возврата. В нём каждое неподтверждённое число (вместе с `%`) SHALL заменяться на «н/д», а в раздел «Оговорки» SHALL добавляться строка на русском о том, что неподтверждённые результатами расчёта числа убраны. Если раздела нет у аналитического ответа, он создаётся в конце. В ответе без разделов строка ставится последним абзацем. Сами убранные числа MUST NOT попадать в оговорку. Ответ без неподтверждённых чисел SHALL отдаваться без изменений.

#### Scenario: Число из результата инструмента
- **WHEN** финальный ответ содержит `412,3`, а в результате инструмента этого хода есть `412.31`
- **THEN** ответ принимается без изменений и без возврата модели

#### Scenario: Выдуманное число перегенерируется один раз
- **WHEN** финальный ответ содержит число `57,4`, которого нет ни в результатах, ни в выжимках, ни в сообщениях пользователя
- **THEN** модель получает сообщение пользователя со списком `57,4` и указанием получить число инструментом или убрать его, ход возвращается модели, а ответ без этого числа принимается без изменений

#### Scenario: Число остаётся после перегенерации
- **WHEN** после единственного возврата ответ снова содержит неподтверждённое число
- **THEN** число в ответе заменено на «н/д», в разделе «Оговорки» есть строка о снятых числах, самого числа в ответе нет, и третьего вызова модели не происходит

#### Scenario: Производное число через derive
- **WHEN** модель посчитала запас до ковенанта через `derive` и пишет его в ответе
- **THEN** число находится в результатах хода, и ответ принимается без изменений

#### Scenario: Числа из сообщения пользователя и прошлого хода
- **WHEN** ответ содержит порог из вопроса пользователя и значение из выжимки прошлого хода
- **THEN** оба числа считаются подтверждёнными

#### Scenario: Годы, номера и счёт не проверяются
- **WHEN** ответ содержит «в 2027 году», пункт списка «1.», обозначение ячейки `P143` и «за 3 года», а ни одного из этих чисел нет в источниках
- **THEN** ответ принимается без изменений

#### Scenario: Процент и доля, знак словом
- **WHEN** ответ содержит «маржа 12,5 %» при источнике `0.125` и «снизится на 30» при источнике `-30`
- **THEN** оба числа считаются подтверждёнными

#### Scenario: Округление сильнее допуска
- **WHEN** ответ содержит `13`, а единственный близкий источник — `12.6`
- **THEN** число считается неподтверждённым

#### Scenario: Лимит хода исчерпан
- **WHEN** частичный ответ после исчерпания лимита хода или времени хода содержит неподтверждённое число
- **THEN** возврата модели нет, число заменено на «н/д» с оговоркой

#### Scenario: Возвраты выключены
- **WHEN** `AGENT_GROUNDING_MAX_RETURNS=0` и ответ содержит неподтверждённое число
- **THEN** число сразу заменено на «н/д» с оговоркой, без возврата модели

#### Scenario: Проверка ответов eval
- **WHEN** eval прогоняет ответы набора на GigaChat
- **THEN** в каждом отданном ответе все проверяемые числа подтверждены источниками хода (100 %), а доля ходов со срабатыванием проверки фиксируется как метрика

### Requirement: FR-14 Язык и гигиена ответа

Ответ SHALL быть на деловом русском независимо от языка вопроса, включая служебные вставки самого агента (раздел невыполненного, отказы). В ответ MUST NOT попадать коды ошибок инструментов, тексты исключений и traceback, ID индекса модели (`IN…`, `OUT…`) и служебные имена инструментов.

#### Scenario: Вопрос на английском
- **WHEN** пользователь спрашивает на английском и ответ дополняется разделом невыполненного
- **THEN** весь ответ, включая этот раздел, — на русском

#### Scenario: Служебные данные в ответе
- **WHEN** проверка гигиены получает ответ с кодом ошибки (например, `missing_input`), `Traceback`, ID `IN12` или именем инструмента `run_scenarios`
- **THEN** каждое такое вхождение помечается как нарушение, а ответ без них на русском — как соответствующий

#### Scenario: Проверка ответов eval
- **WHEN** eval прогоняет ответы набора
- **THEN** ни один ответ не содержит кодов ошибок, traceback, ID индекса и имён инструментов
