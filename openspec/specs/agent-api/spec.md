# agent-api Specification

## Purpose

HTTP-интерфейс сервиса для агента v2: выбор движка агента, неизменный контракт запросов и ответов, коды ошибок и изоляция пользователей на уровне API.

## Requirements

### Requirement: FR-20 Переключатель движка агента

Сервис SHALL обслуживать `/api/v1/invoke-agent` агентом v1 или v2 в зависимости от `AGENT_ENGINE` (`v1` по умолчанию). Переключение и откат SHALL выполняться изменением переменной окружения и перезапуском, без пересборки образа. При `AGENT_ENGINE=v1` поведение сервиса SHALL оставаться прежним.

#### Scenario: По умолчанию работает v1
- **WHEN** `AGENT_ENGINE` не задан
- **THEN** `/invoke-agent` обрабатывает агент v1, как до появления v2

#### Scenario: Включён v2
- **WHEN** `AGENT_ENGINE=v2`
- **THEN** `/invoke-agent` обрабатывает агент v2, и ответ имеет тот же формат: ZIP с `txt_response.txt` и `generated/agent_output.xlsx`

#### Scenario: Откат без пересборки
- **WHEN** после работы на v2 переменная `AGENT_ENGINE` возвращена в `v1` и сервис перезапущен
- **THEN** запросы снова обрабатывает v1 тем же образом

#### Scenario: Неверное значение
- **WHEN** `AGENT_ENGINE` имеет значение, отличное от `v1` и `v2`
- **THEN** сервис не стартует и сообщает допустимые значения
